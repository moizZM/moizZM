# FPGA Tilt-Controlled Robot

[← All projects](../README.md#fpga-tilt-robot) · [Profile](../../README.md#projects-to-start-with)

**Status:** Completed university project

An ADXL362 accelerometer and FPGA produced tilt data while an ESP32 controlled motors through PWM.

<p align="center"><img src="../../assets/portfolio/fpga-tilt-robot.jpg" alt="FPGA Tilt-Controlled Robot — project visual" width="520" /></p>

## Problem

Convert FPGA tilt measurements into a wireless vehicle-speed reference.

## My contribution

Created seven-segment display IP and supported the ESP32 motor setup, IR sensors, communication and integration.

## Validation and result

Integrated tilt sensing, wireless communication, motor control and obstacle sensing.

## Tools

FPGA · ADXL362 · ESP32 · Bluetooth · UDP · PWM · IR sensors
